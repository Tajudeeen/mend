# Contributing

Use the pinned Node/pnpm toolchain and frozen lockfile. Keep domain rules separate from UI, persistence and provider adapters. Run typecheck, lint, native tests, Vitest and the appropriate target build before proposing changes.

Never commit credentials, fabricated live API receipts or invented impact results. Preserve applied migrations. Cultural claims must be reproducible from stored evidence. Every applied assignment change needs an approved, current proposal. New constraints need meaningful feasible/infeasible examples.

The primary production target is Next.js/Node with Supabase/Prisma. Keep the temporary Sites compatibility adapter explicit until a verified migration is complete.
