# Known limitations

Reviewed 2026-10-29. This is the current list; dated observations remain in `docs/VERIFICATION.md`. Updating a release must review this document and preserve the host gates in `docs/HOST_REQUIREMENTS.md`.

| Area                  | What is established                                                                                        | What remains open                                                                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Product boundary      | Plan investigation, proposals, approval and reports                                                        | No booking requests, supplier quote inbox, payments, automatic booking or messages                                                                |
| Live integration      | Prior three-audience artist Qloo receipts and conditional Groq proposals persisted after PostgreSQL reload | Approved real-event recovery, live vendor quality and better-choice evidence                                                                      |
| Live evaluation       | Opt-in 50-case real-model harness exists                                                                   | Actual credentialed run, baseline and protected required merge-check configuration. Inputs are synthetic; this is not a Qloo or impact evaluation |
| Authenticated testing | Prior production event writes/readback and bounded role probe; staged two-account browser/API probe added  | Execution on an isolated staging deployment; fresh signup, email confirmation and GitHub OAuth end to end                                         |
| Terms resolution      | Synthetic live-policy fixture exercises unknown -> edit -> repropose -> approve and duplicate refusal      | Full persisted live-evidence approval with real confirmed organizer facts and human action                                                        |
| Physical devices      | Selected 320–430 CSS viewport checks                                                                       | Actual Android Chrome and iOS Safari, keyboard/date-picker/assistive-technology behavior. No participant photo-upload feature is claimed          |
| Storage isolation     | Bounded production role checks and local owner/CAS tests                                                   | Every child-table policy and two real browser identities on deployed staging                                                                      |
| Integrity             | Canonical stored-response hashes, derived-affinity and context checks                                      | Issuer authentication, independently immutable audit history or proof of real-world facts                                                         |
| Planning              | Bounded alternatives using supplied constraints                                                            | Global optimality, attendance, sales or guaranteed preference predictions                                                                         |
| Site                  | Conceptual dimensions, capacity and power                                                                  | Surveyed safety plan, physical clearance and nonzero spacing                                                                                      |
| Reports               | In-page full JSON and sample verifier path                                                                 | Original browser download handoff on physical devices                                                                                             |
| Impact                | Local study instrument preserves failed/unfinished trials                                                  | Actual consented organizer participants and measured benefit                                                                                      |
| Operations            | Verification reports and event audit/run records                                                           | Deployed centralized trace dashboard, timed isolated backup/restore drill, real-device service access                                             |
| Dependencies          | Pinned lockfile and secret-pattern scan                                                                    | Executed dependency-vulnerability gate and standard SBOM pipeline                                                                                 |
| Submission            | Public app/source and MIT retained                                                                         | Entrant eligibility, actual submission, finalist availability and continuing judge access                                                         |

Never mark a missing configuration, skipped external test or fixture run as a passing live observation. A new build does not repeat prior live evidence automatically.
